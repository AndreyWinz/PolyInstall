# PolyInstall: HTML5 Validator & Static Web Server Suite

This execution folder delivers standalone sandboxed tool configurations matching HTML development pipelines, adding validation systems (W3C Nu Checker Engine) and local dev content servers without system path clutter.

Target Tool Assemblies: W3C Nu Checker v20.6.30 & http-server via Node Modules

---

## 1. Native Script Bootstrap Frameworks

### Linux Framework Platforms (GNU Bash Driver Script)
Pulls compiled structural validator modules, configures script execution redirect wrappers natively inside your userspace home directories, and downloads the static web server.

```bash
chmod +x linux/install.sh
./linux/install.sh
```

### macOS Environments (Zsh System Toolchain Script)

Directly maps architecture components, builds isolated runtime redirection parameters targeting Java engines cleanly, and updates active shell config properties.

```bash
chmod +x macos/install.zsh
./macos/install.zsh
```

### Windows Administrative Networks (PowerShell Module Core)

Pulls zip packages, extracts core objects to user sandboxes, builds command batch wrappers dynamically, and mounts local web servers seamlessly.

```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process
.\windows\install.ps1
```

## 2. Cross-Language Native TypeScript Application Engine

The typescript/ folder cluster provisions a full system-level installer orchestration tool modeled entirely in TypeScript. It can be parsed down into functional JavaScript using the active tsc toolset established during the preceding step of PolyInstall.
#### Compilation Protocol
#### Compilation via TypeScript Engine CLI Handles

To process and compile the TypeScript source logic array down to execution JavaScript arrays, use the terminal pathways:

```bash
cd typescript/
tsc
node ../javascript/install.js
```

### Terminal Environment Refreshes

To append tools paths securely into your active shell interface layout immediately without applying a hardware system reset, refresh configuration fields:

```bash
# Unix environments synchronization updates
source ~/.bashrc # or source ~/.zshrc

# Tool verification execution runs
html-validate --version
http-server --version
```
