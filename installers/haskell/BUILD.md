# PolyInstall: Haskell Execution Compiler & Build Suite

This deployment directory houses autonomous configurations for mounting the full standard functional Haskell developer platform infrastructure tools without requiring third-party configuration wrapping scripts.

Target Bootstrap Engine Version: GHCup v0.1.30.0

---

## 1. Native Script Bootstrap Implementations

### Linux Environments (GNU Bash Protocol)
The execution module pulls standard compiled operational binaries from the central server structures, targets user space directories safely, and provisions background headless tasks to establish the stable base compiler.

```bash
chmod +x linux/install.sh
./linux/install.sh
```

### macOS Operating Spaces (Zsh Native Interface)

Directly maps architecture components, provisions execution configurations within user accounts safely, and pipes standard path profiles natively into active configurations profiles.
Bash

```bash
chmod +x macos/install.zsh
./macos/install.zsh
```

### Windows Shell Implementations (PowerShell Execution Layer)

Safely orchestrates native file transmissions, triggers automated installations of the compiler engine subsystems, and registers environment path mutations globally for user definitions.
PowerShell

```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process
.\windows\install.ps1
```

## 2. Cross-Language Native C# Engine

The csharp/ code cluster relies on a modular .NET framework engine logic mapping. It can be compiled and launched using the active .NET Core software kit engine generated in the preceding PolyInstall process modules.
Compilation Protocol
For All Desktop Ecosystem Architectures

If an operational installation of the .NET SDK tool suite is already running inside your system console environment variables, trigger the compiler manually:

```bash
cd csharp/
dotnet build -c Release
dotnet run --project haskell.csproj
```

### Path Activation Steps

To apply target binary locations directly into your shell environment structures without forcing a hard workstation or terminal restart loop cycle, execute paths synchronization mappings:
Bash

```bash
# Unix environments
source ~/.bashrc # or source ~/.zshrc

# Structural validation checks
ghc --version
cabal --version
```
