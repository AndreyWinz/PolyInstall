# PolyInstall: Rust Engine Toolchain Installer Suite

This automated setup profile handles downloading, verifying, and launching the official Rust standalone compiler infrastructure tools securely inside localised application spaces.

Target Toolchain Core: rustup-init (Latest Stable Channel)

---

## 1. Native Script Bootstrap Frameworks

### Linux Platforms (GNU Bash Engine Matrix)
Drives structural evaluations, fetches targeting platform executable blocks, and handles headless execution states without triggering interactive prompt overlays.

```bash
chmod +x linux/install.sh
./linux/install.sh
```

### macOS Spaces (Zsh Environment Setup Script)

Maps execution files natively to Apple Silicon (Aarch64 Architecture builds) or standard configuration channels, mounting configuration variables safely into userspace fields.
Bash

```bash
chmod +x macos/install.zsh
./macos/install.zsh
```

### Windows Shell Networks (PowerShell Module System)

Pulls targeted standalone MSVC binary drivers, invokes silent defaults execution routines safely, and updates internal system variable registry maps.

```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process
.\windows\install.ps1
```

## 2. Cross-Language Native Haskell Automation Engine

The haskell/ workspace defines a pure functional installer tool layout written from scratch in Haskell code architectures. It can be compiled and triggered using the GHC tools infrastructure generated within the preceding step of the PolyInstall suite.
#### Compilation Framework
#### Compilation via Compiler Binary CLI Handles

Compile the standalone system orchestration file directly via the terminal interface tracking variables:

```bash
cd haskell/
ghc -O2 install.hs -o rust_installer
./rust_installer
```

### Profile Synchronisation Check

To activate your newly generated compiler states and Cargo application platforms inside your active terminal context window without requiring a hard workstation restart, cycle your profile paths manually:

```bash
# Unix terminals execution sync
source ~/.bashrc # or source ~/.zshrc

# Core toolchain status verification runs
rustc --version
cargo --version
```
