# PolyInstall: TypeScript Compiler (`tsc`) Toolchain Suite

This installation folder provides explicit bootstrap automation vectors designed to mount the standalone TypeScript compilation engine over localized userspace environments without needing administrative file elevation access.

Target Package Dependency: TypeScript (Latest Stable Release Channel via npm)

---

## 1. Native Script Bootstrap Frameworks

### Linux Operating Spaces (GNU Bash Orchestrator)
Safely overrides standard global system location arrays, maps localized dependency targets directly into user configuration files, and pulls the compiler tool asset strings.

```bash
chmod +x linux/install.sh
./linux/install.sh
```

### macOS Shell Integration (Zsh Automated Pipeline)

Configures localized prefix variables cleanly, keeping standard application configurations separate from root file domains while registering environmental paths.

```bash
chmod +x macos/install.zsh
./macos/install.zsh
```

### Windows Shell Terminals (PowerShell Core Matrix)

Updates transient tracking strings to verify Node package managers, forces sandbox execution filters, and updates user registry paths cleanly.

```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process
.\windows\install.ps1
```

## 2. Cross-Language Native JavaScript Application Engine

The javascript/ subdirectory exposes a completely native installation orchestration runner script written entirely in JavaScript. It can be triggered using the custom isolated Node.js environment configured during the previous stage of PolyInstall.
Compilation Framework
Running Execution Pipelines via Local Node Runtime Handles

Run the installation deployment engine file directly from source within your system shell variables:

```bash
cd javascript/
node install.js
```
